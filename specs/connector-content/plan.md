# CONN-MEDIA-DOWNLOADER-CONNECTOR-CONTENT — Implementation plan

Governing spec: [spec.md](spec.md). Rows: [requirements.md](requirements.md).

## Summary

This plan states how `media-downloader` delivers the rows of `CONN-MEDIA-DOWNLOADER-CONNECTOR-CONTENT`. The live caller is the `media-downloader` console script. The owner is the `media_downloader` package. The rows reuse the `scion-sdk` helpers and add no second authority. The plan changes no runtime code.
